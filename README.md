# CS231n 2025

Stanford CS231n 2025 春季课程的个人代码实现与实验。

## 代码目录

```text
assignments/
  assignment1/   # kNN、Softmax、两层网络、图像特征、全连接网络
  assignment2/   # 归一化、Dropout、CNN、PyTorch、RNN
  assignment3/   # Transformer、自监督学习、DDPM、CLIP/DINO
exercises/       # 独立练习与核心函数重写
```

各作业保留 notebook 与配套 cs231n 包的相对位置。目录不代表作业已完成。

当前上传范围为代码；课程讲义保留在本地，学习笔记后续单独提供。
数据集、模型权重、环境、缓存和临时输出不纳入版本控制。
